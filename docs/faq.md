# 常见问题

## 播放相关

### 房间号在哪看

斗鱼网页版地址里 `douyu.com/` 后面那串数字。比如 `douyu.com/9999`，房间号就是
`9999`。

靓号也能直接用。程序内部会自动识别靓号与真实房间号指向的是同一个房间，不会重复
开窗。

### 一直显示加载中 / 反复重试

依次排查：

1. 主播是否真的在播 —— 未开播时取不到流
2. 浏览器里能否正常打开这个房间 —— 不能的话是网络或平台问题，与本程序无关
3. 换个房间试试 —— 只有个别房间不行，可能是该房间用了特殊的流格式
4. 手动降低清晰度 —— 高码率流在带宽不足时会一直缓冲

程序对取流失败是无限重试的（退避上限 5 秒），所以"一直在重试"通常意味着上游确实
拿不到流，而不是程序卡住了。

### 画面卡顿、掉帧

同看多路高清直播对硬件要求不低。一个 1080p60 的流解码开销就不小，叠加多路再加上
全屏弹幕的渲染，很容易吃满 GPU。

按效果排序的缓解手段：

1. 手动降低清晰度 —— 效果最明显
2. 减少同时播放的窗口数
3. 关闭弹幕
4. 关掉其他占用显卡的程序

### 某条线路一直卡

在窗口控制栏里换一条线路。斗鱼会为同一个房间下发多条 CDN 线路，各条的负载和到你这里
的路由质量不一样，换一条往往就好了。清晰度也可以一起降一档试试。

### 声音和画面不同步

先试试重载那个窗口。

如果是主播开多人连麦时出现的，通常在连麦结束后自行恢复 —— 这类失步源于主播端在
加人或切场景时重建了音频编码器。程序已针对这种情况做了时钟重锚处理，若仍然发生，
欢迎提 Issue 并注明房间号与当时的场景。

### 有的房间没声音

检查四处：窗口自己的音量、全局音量、是否开了全局静音（右下角菜单里）、以及是否有别的
房间处于 SOLO 状态 —— SOLO 会把其余房间全部静音。Windows 音量合成器里也可能单独把
程序静音了。

### 怎么只听一个房间的声音

在窗口控制栏点 SOLO，其余房间会全部静音。再点一次退出。控制台上会显示当前 SOLO 的是
哪个房间，点那里也能退出。

### 回放怎么用

支持回放的直播间开窗后，控制栏会出现进度条，可以拖动。不支持回放的房间不显示进度条。

## 弹幕相关

### 弹幕不显示

1. 右下角菜单里的弹幕总开关是否打开
2. 该窗口是否单独关闭了弹幕（控制栏上的按钮）
3. 过滤规则是否把弹幕全过滤掉了 —— 设置里检查关键词、等级、长度这几项
4. 冷门房间可能确实没人说话

### 关掉某个窗口的弹幕后，通知也没了？

不会。单窗口关闭弹幕只是停止在屏幕上显示，弹幕连接依然保持，所以进场提醒、礼物
提醒、关注用户通知、房间榜单和弹幕速率统计都照常工作。

### 发不出弹幕

需要先登录。另外斗鱼本身对发言有限制：等级要求、发言间隔、房间禁言、账号被禁言
等，这些限制程序无法绕过。

### 彩色弹幕选项是灰的

彩色弹幕需要对应的账号权限（等级或贵族等），权限由斗鱼判定。程序只显示你当前在
该房间实际可用的颜色。

## 账号相关

### 登录安全吗

登录在斗鱼自己的登录页面中完成，账号密码不经过本程序的任何代码。登录后的凭据只存
在你本机的数据目录里，不上传任何服务器。

但**本机的凭据安全取决于你本机的安全状况**。便携版的 `LiveDeckData` 目录里包含
登录状态，不要上传网盘或分享给他人。公用电脑上用完请退出登录。

### 一键签到 / 一键续牌会不会封号

**有风险，请自行判断。**

这两个功能的实质是由程序批量执行原本要手动点的操作，这类自动化行为可能违反斗鱼
用户协议，也可能被风控识别为异常。开发者无法预知平台的判定标准，不对账号处罚承担
责任。

不用这两个功能不影响看直播 —— 核心的观看和弹幕功能根本不需要登录。详见
[免责声明](../DISCLAIMER.md#三关于账号功能的重要风险提示)。

### 一键签到会动我的关注列表吗

会，但会还原。部分签到任务（例如星推关注任务）要求关注并浏览指定的活动直播间才能完成，
程序会在签到结束后自动取消这些关注、并从观看历史里移除对应记录。

还原动作有失败的可能（网络中断等），此时执行结果里会明确报出"关注状态还原失败"或
"观看历史恢复失败"，你可以手动清理。介意这个行为请不要使用一键签到。

### 登录状态老是掉

斗鱼的凭据有有效期。设置里可以手动刷新登录状态。如果频繁掉登录，可能是账号在别处
登录导致的。

## 监控与导演模式

### 监控列表什么时候会通知

开播和下播都会通知，两个开关在设置里独立控制，可以只留开播。点击开播通知会直接把该房间
加为播放窗口，点下播通知只是把程序窗口调到前台。

托盘菜单里能看到监控列表当前有几个在播。

### 导演模式是做什么的

它盯着各个房间的热度变化，谁在快速上涨就给谁加高亮边框，帮你在多个窗口里第一时间注意到
哪边有事发生。

参与评分的指标有弹幕速率、贵宾数、热度、礼物，权重可以自己配，也能整体关掉。轮播和没
开播的房间不参与判定 —— 那种情况下的弹幕和贵宾只说明有人在等，跟内容精彩程度无关。

## 布局与设置

### 有没有一键排列

有。布局菜单里提供平铺、主次、横排、竖排四种预设排列，一键把当前所有窗口摆好，之后仍可
以手动微调。

### 布局会自动保存吗

会。当前布局实时保存，关掉程序再打开还是原样。

也可以在布局管理里把当前布局命名保存成一套，之后随时切回来，还能导出成文件备份。

### 窗口拖不动

大概是被锁定了。选中窗口后底部会弹出操作面板，里面有解锁按钮；或者右键窗口在菜单
里解锁。

### 怎么精确对齐窗口

拖动时靠近屏幕边缘或别的窗口会自动吸附，同时显示对齐辅助线。想放在吸附点之外的
位置，按住 `Alt` 再拖就能临时关掉吸附。

### 设置能备份吗

设置面板里可以导出成文件，也可以导入恢复。恢复默认值只影响设置，不动布局、监控
列表和登录状态。

## 更新与公告

### 怎么检查更新

程序会自动检查，有新版本时在设置面板里提示。也可以在「设置 → 关于与更新」里手动
点检查。

检查只请求一个很小的静态文件，不上传任何个人信息。

### 检查更新失败

大陆网络访问 GitHub 不稳定，程序会依次尝试多个加速地址，全都失败时会显示上次成功
检查的结果。可以稍后再试，或直接访问
[Releases 页面](https://github.com/0xyk3r/livedeck-release/releases/latest) 手动看。

不想让程序发这类请求的话，可以在设置里关闭自动检查更新。

### 程序会自动下载安装更新吗

不会。检测到新版本只是在界面上提示，点击后是在你的系统浏览器里打开下载页面，下载
和安装都由你自己操作。程序不会自行下载或执行任何可执行文件。

### 更新会丢配置吗

不会。安装版覆盖安装保留全部数据。便携版用新 exe 替换旧的，保留同级的
`LiveDeckData` 目录即可。

建议更新前顺手导出一次布局和设置。

## 其他

### 日志在哪

- 安装版：`%AppData%\LiveDeck\logs\`
- 便携版：exe 同级的 `LiveDeckData\logs\`

按日期分文件，命名如 `livedeck-2026-08-29.log`。

在文件资源管理器地址栏里粘 `%AppData%\LiveDeck\logs` 回车可以直接打开。

提 Issue 时附上出问题当天的日志会快很多。日志里不含账号密码，但可能包含房间号和
昵称，介意的话可以先看一遍再贴。

### 关闭窗口后程序还在后台

默认行为是最小化到系统托盘，托盘图标右键可以退出。想改成点关闭就直接退出，在设置
里改「关闭按钮行为」。

### 会不会支持虎牙 / B 站

程序内部的平台接入是按接口抽象设计的，加平台在架构上可行，但每个平台的取流和弹幕
协议都要单独实现和长期维护。目前没有时间表。

### 有 macOS / Linux 版吗

暂时没有。

### 怎么反馈问题

到 [Issues](https://github.com/0xyk3r/livedeck-release/issues) 提。麻烦附上版本号、
复现步骤，以及相关日志。
