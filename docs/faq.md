## 播放相关

### 支持哪些平台

支持斗鱼、虎牙和哔哩哔哩直播，斗鱼／虎牙官方录像，以及 B 站视频（含分 P）与部分主播公开发布的直播回放。直播、录像和视频可以混排在同一个布局中。当前发布的是 Windows x64 桌面版。

回看弹幕补全、PK 比分条、鱼吧、一键签到与一键续牌目前只有斗鱼有。

### 房间号在哪看

各平台网页版地址里的那串数字，比如斗鱼 `douyu.com/9999`、虎牙 `huya.com/11342412`、B 站 `live.bilibili.com/21452505`。也可以不找房间号，直接把整条链接粘进去；B 站还支持 BV / AV 号和 App 分享文本。

斗鱼靓号也能直接用。程序内部会自动识别靓号与真实房间号指向的是同一个房间，不会重复开窗。

### 一直显示加载中 / 反复重试

依次排查：

1. 主播是否真的在播 —— 未开播时取不到流
2. 浏览器里能否正常打开这个房间 —— 不能的话是网络或平台问题，与本程序无关
3. 换个房间试试 —— 只有个别房间不行，可能是该房间用了特殊的流格式
4. 手动降低清晰度 —— 高码率流在带宽不足时会一直缓冲

程序会尝试恢复可重试的故障；持续失败后可能等待下一次探测。下播、离线、需要登录或没有观看权限时，应按窗口提示处理。可以手动重试或更换线路，仍有问题时附上调试报告反馈。

### 画面卡顿、掉帧

同看多路高清直播对硬件要求不低。一个 1080p60 的流解码开销就不小，叠加多路再加上全屏弹幕的渲染，很容易吃满 GPU。

按效果排序的缓解手段：

1. 暂时关闭插帧和超分，判断是否为画面处理负载
2. 降低清晰度或减少同时播放的窗口数
3. 关闭弹幕，检查是否为渲染负载
4. 关掉其他占用显卡的程序

启用本地字幕也会增加 CPU 负载。插帧的目标帧率与实际输出不同，可从「调试信息」查看实际后端和帧率。

### 某条线路一直卡

在窗口控制栏里换一条线路。平台会为同一个房间下发多条 CDN 线路，各条的负载和到你这里的路由质量不一样，换一条往往就好了。清晰度也可以一起降一档试试。

## 声音与对齐

### 声音和画面不同步

先重载窗口、切换线路，并对照平台网页判断是否为来源本身的问题。启用了画面或声音增强时，也可暂时关闭增强进行对比。

连麦加入成员或切换场景时，来源可能短暂失步。持续发生时，请注明房间、线路、时间及是否启用增强，并附调试报告反馈。

「时间微调」会一起移动画面与声音，用于调整不同直播之间的先后，不能单独修复同一路直播里的音画失步。

### 多个比赛视角不同步，怎么对齐

从直播播放器「更多控制 → 时间微调与多路对齐」进入。可以手动增加 0–30 秒附加延迟，按 0.1、0.5 或 1 秒微调；0 表示不添加额外延迟，不代表平台直播本身没有延迟。

也可以选择另一路直播作为参照，用「共同声音」采集约 24 秒的两路音轨并寻找时差，或用「画面时钟」同时截图，手动填写同一个游戏时钟的读数。查看建议后点击「应用对齐」才会调整播放；画面和声音一起移动，弹幕仍然实时显示。

声音比对适合两路包含相同比赛或游戏声音的情况，识别范围为前后各 12 秒。解说盖住游戏声、音轨不同、重复音乐或时差过大时可能无法匹配，可改用画面时钟或手动微调。画面时钟需要自己读数，不会自动识别截图中的文字。分析在本机进行，不使用麦克风，也不上传声音或截图。

### 有的房间没声音

检查四处：窗口自己的音量、全局音量、是否开了全局静音（标题栏或混音面板的声音按钮）、以及是否有别的房间处于独听（SOLO）状态 —— 独听会把其余房间全部静音。Windows 音量合成器里也可能单独把程序静音了。

### 怎么只听一个房间的声音

在窗口控制栏点独听（SOLO），其余房间会全部静音。再点一次退出。混音面板会显示当前独听的房间，也可在那里退出。星幕临时查看期间按住 `A` 可临时独听当前画面，松开恢复原来的声音选择。

### 不同主播的声音忽大忽小怎么办

在「音量与混音」或「设置 → 音频增强 → 多路响度」开启响度平衡。各路累计约 24 秒有效声音后完成校准，让常态音量更接近；暂停、卡顿或没有有效声音时会继续等待。可以逐路微调或重新校准，100% 表示校准后的标准音量。

响度平衡保留节目原有的强弱变化；同一路突然的大声可尝试音频增强中的夜间模式。关闭响度平衡会恢复各路普通音量，静音与独听选择保留。

### 对白增强、降噪和夜间模式怎么用

在播放器「更多控制 → 音频增强」主动开启，选择访谈、游戏直播、音乐预设，或分别调整对白增强、背景降噪与夜间模式。设置页保存默认强度，各窗口可临时调整，并通过「对比原声」判断效果。

场景预设需要手动选择，不会自动识别节目或自动开启增强；选择预设也不会替你改变夜间模式。对白增强调整音色，不是把人声和配乐分离。

处理在本机完成，不使用麦克风，不上传音频，不需要额外下载模型。较强降噪可能削弱音乐、尾音或游戏音效；夜间模式用于减小同一路节目的音量起伏。更换房间或录像、关闭窗口或重启应用后，需要重新主动开启。

## 录像、视频与赛事

### 回放怎么用

支持回放的直播间开窗后，控制栏会出现进度条，可以拖动。不支持回放的房间不显示进度条。

### 怎么查 B 站主播的直播录像

打开「发现 → B 站 → 录像」，输入直播房间号、主播空间链接或该主播的视频链接；也可直接选择正在看的 B 站主播。找到回放后，可以选择分 P 并加入布局观看。

这里只展示主播已公开发布的直播回放，不是所有主播都会提供，也不代表完整的直播历史。暂时无法读取时可稍后刷新；「暂无公开回放」不代表该主播从未开播。

### 斗鱼公会目录去哪了

提供公会数据的第三方服务已停运，1.3.0 移除了公会目录和名册补录。仍可通过分类、搜索、关注查找房间；团播或赛事活动可以在「发现 → 斗鱼 → 直播 → 团播活动」中查找。团播活动并非完整的公会名册，也不保证收录所有活动。

### 怎么搜索 B 站视频

打开「发现 → B 站 → 视频」，输入关键词，可按综合、最多播放或最新发布排序，点击结果加入布局。也可在快速添加或添加来源中粘贴视频链接、BV／AV 号或分享文本。主播公开直播回放继续从「录像」页查找。

### 虎牙赛事、选手视角和直播回看在哪

在「发现 → 虎牙 → 直播 → 赛事直播」查看官方赛程、主直播与二路。有效赛事房间的播放器按上游能力提供 POV 与回看入口，不是每场都有；过期视角或平台未开放的入口不会当作可用内容展示。

直播回看只在平台明确免认证，或当前账号确认有相应权限时开放；能够读到高光点不代表能免费回看。直播回看目前只使用本窗口实际收到的弹幕，官方已归档录像仍从「录像」页查看。

## 画面增强

### 画面插帧和超分怎么开启

在「设置 → 画面增强」选择处理方式、分辨率与帧率，再从播放器「更多控制」开启画面插帧或超分辨率。这两项为 BETA，默认关闭。画面增强总共最多处理两路，其中超分最多一路；超分可单独使用，与插帧组合时使用两倍、最高 120 fps。

NVIDIA VFX 和通用 GPU 插帧提供 2／4／8 倍及指定帧率，AMD AMF 仅支持两倍。默认两倍、120 fps 上限、1080p 处理分辨率；480 fps 是可选配置目标，8 倍为实验性选项，实际帧率取决于显卡、显示刷新率、来源和负载。高分辨率视频选择较低处理分辨率时会损失细节，遇到负载过高可以降低处理分辨率或关闭增强。

### 为什么插帧、超分或 HDR 不可用

NVIDIA 原生方式需要在设置中安装可选 VFX 组件，并通过所选模型的兼容性检查；插帧模型要求 Ada／Blackwell 显卡，超分的支持范围有所不同，以实际检查结果为准。AMD 依赖驱动能力，通用 GPU 需要硬件加速与 WebGL 2。组件已安装不代表显卡能运行所选模型。

插帧与超分适用于可采样、正常速度的 15–60 fps SDR 内容，HDR、倍速和系统原生画中画使用原视频。倍帧结果超过所选上限时也保留原视频，例如 60 fps 来源选择四倍需至少 240 fps 上限，八倍需 480 fps。HDR 播放还需要来源提供相应画质、账号有权限、显卡能解码且系统启用 HDR 显示输出。虎牙清晰度菜单会保留受限项及原因，不会绕过登录或 VIP 权限。

### 为什么只安装组件还不能插帧，或者只有超分可用

插帧与超分使用不同的能力或模型，要分别检查。NVIDIA 标准超分可支持的显卡范围比 VFG 插帧更广；所选画质档位也要通过实际加载检查。AMD 的插帧和超分同样分别依赖驱动能力。

到「设置 → 画面增强」查看所选项目的兼容性结果。安装成功不等于显卡兼容，也不保证所选分辨率和帧率能稳定运行。

### 画面增强为什么自动回到原视频

HDR、倍速、系统原生画中画、不可采样来源或持续处理不足时，会使用原视频。可以降低处理分辨率、倍率或目标帧率，再重新开启；「更多控制」的状态和调试信息会显示原因。

插帧把高分辨率来源缩到较低处理分辨率时可能损失细节，后续超分不能保证恢复原来的细节。需要更清晰的来源时，应先选择平台实际可用的高画质。

## 实时字幕

### 实时字幕有哪些模式，会上传什么

点击播放器控制栏的语言图标开关字幕，悬停图标可选择识别方式、语音语言、翻译语言及原文／译文／双语显示；也可从「更多控制」打开字幕选项，完整设置在「设置 → 实时字幕」。每次最多一路，需要主动开启，不使用麦克风。

- **本地 ASR + Index-Translate**：在本机识别语音，不上传音频；翻译时只向 Index-Translate 发送字幕文字。语音支持中、英、日、韩及自动识别，目标语言可选中、英、日、韩。
- **Echo S2TT**：将播放器音频片段发送至官方演示服务，返回原文与译文，无需本地语音模型。语音支持中文、英文及这两种语言的自动识别，目标语言可选中、英、日、韩；只显示原文仍需要在线识别。

如不希望发送音频，选择本地模式；如不希望发送字幕文字，在本地模式选择「原文」。「优先使用视频已有字幕」会使用可读取的现成字幕，在选择翻译显示时发送字幕文字，没有现成字幕时使用所选语音模式。字幕服务的数据使用与可用性由服务提供方决定，详见[隐私说明](../DISCLAIMER.md#八隐私)。

### 视频已有字幕时，也必须下载语音模型吗

开启「优先使用视频已有字幕」后，有权限读取的现成字幕可以直接显示或翻译，无需进行语音识别，也不需要为这一路下载语音模型。显示译文或双语时会向 Index-Translate 发送字幕文字。

没有可读取的字幕时会回到所选语音模式：本地模式需要模型，Echo 会发送播放器音频。关闭优先选项可强制使用语音识别。

### 怎么把实时字幕切到另一窗口

在目标播放器主动开启实时字幕，上一窗口会停止识别。只修改字幕样式或原文／译文／双语显示，不会把识别切到另一个窗口。

### 本地字幕要下载什么，为什么会有延迟

在「设置 → 实时字幕」下载轻量模型（约 142 MiB）或标准模型（约 466 MiB），首次使用同时下载约 8.5 MiB 的 Windows CPU 引擎，需要能访问 GitHub 与 Hugging Face。默认引擎不要求独立显卡，下载后经校验才启用。

字幕要等待声音成句、识别和翻译，因此会有可见延迟。背景音乐、多人说话、快语速、设备性能与网络排队都可能影响准确性和速度。Echo 使用官方演示服务，可用性和限流由上游决定；两种模式都为 BETA。

### 字幕太大、太宽或遮住画面怎么办

在「设置 → 实时字幕 → 字幕样式」调整字号、文字与背景颜色、不透明度、宽度及每种语言行数，设置页提供预览和恢复默认。可以向上滚动查看最近的内容，再点击「回到最新」继续跟随。

字幕可在播放器全屏中显示，系统原生画中画无法带出字幕覆盖层。

## 弹幕相关

### 弹幕不显示

1. 控制台的「全局弹幕」开关是否打开
2. 该窗口是否单独关闭了弹幕（控制栏上的按钮）
3. 过滤规则是否把弹幕全过滤掉了 —— 设置里检查关键词、昵称、UID、等级、长度这几项，注意昵称、UID、等级是按平台分别设置的
4. 冷门房间可能确实没人说话

### 关掉某个窗口的弹幕后，通知也没了？

不会。单窗口关闭弹幕只是停止在屏幕上显示，弹幕连接依然保持，所以进场提醒、礼物提醒、关注用户通知、房间榜单和弹幕速率统计都照常工作。

### 发不出弹幕

需要先登录对应平台的账号。另外平台本身对发言有限制：等级要求、发言间隔、房间禁言、账号被禁言等，这些限制程序无法绕过。

### 彩色弹幕选项是灰的

彩色弹幕需要对应的账号权限（等级或贵族等），权限由平台判定。程序只显示你当前在该房间实际可用的颜色。

### 怎么找到自己刚发的弹幕

登录对应平台后，自己的弹幕会显示专属标记与下划线。识别依据是当前登录账号，昵称相同的其他用户不会被标成自己。

### 神秘人的消息卡能看到真实昵称吗

不能。斗鱼神秘人弹幕有独立样式，但消息卡仍显示平台提供的匿名身份。

### 高能弹幕、上头条或 SC 的显示时间怎么变短了

1.4.0 默认使用精简展示。可以在「设置 → 房间事件」选择平台，找到高能弹幕、上头条或 SC，将展示方式改为「跟随平台」，沿用平台剩余时长。

同一分组还可设置金额门槛。斗鱼按优惠前金额判断门槛，显示的实付金额可能更低；其他平台按可读取的人民币金额处理。金额门槛也影响首次飘屏。

## 账号相关

### 登录安全吗

登录在平台官方页面完成。登录凭据保存在本机，并用于向对应平台认证、读取账号内容和执行你选择的互动；不会提交给开发者或无关服务。

但**本机的凭据安全取决于你本机的安全状况**。便携版的 `LiveDeckData` 目录里包含登录状态，不要上传网盘或分享给他人。公用电脑上用完请退出登录。

### 用第三方工具登录、发弹幕会不会封号

**有风险，请自行判断。** 在平台看来，通过本程序发弹幕、关注、切换粉丝牌等操作来自非官方客户端，可能违反平台用户协议，也可能被风控识别。三个平台都一样。

### 一键签到 / 一键续牌 / 批量弹幕任务会不会封号

**风险更高，请自行判断。** 这些功能只面向斗鱼账号，由程序批量执行原本需要手动操作的任务，可能违反斗鱼用户协议，也可能被风控识别为异常。开发者无法预知平台的判定标准，不对账号处罚承担责任。

不用这些功能不影响看直播，观看和显示弹幕不需要登录。详见 [免责声明](../DISCLAIMER.md#三关于账号功能的重要风险提示)。

### 粉丝牌总览在哪，能做什么

从「工具 → 粉丝牌总览」进入，连接相应平台账号后，就能集中查找斗鱼、虎牙与 B 站的粉丝牌，按平台、主播、等级或点亮状态筛选，查看成长并进入直播间。斗鱼、虎牙可展示平台提供的任务状态，B 站主要展示成长数值与点亮状态。

斗鱼还可查看生效的主播双倍卡与可读取的综合倍率；综合倍率无法读取时会注明卡片倍率。在粉丝牌详情可主动向对应房间赠送背包荧光棒，赠送会消耗所选数量的道具。仅查看总览不会自动发弹幕或赠礼。

### 批量弹幕任务会发到哪些房间

范围是总览已加载的全部斗鱼粉丝牌房间，不受当前平台筛选、搜索或分页影响。程序检查任务状态后，跳过已完成或没有对应任务的房间，向待完成的房间逐个发送你填写的弹幕；状态不明时不发送，发送失败时停止。

开始前可以修改内容，过程中可以停止后续发送；已经提交的请求仍可能完成。默认文案中的「+10 亲密度」不是奖励承诺，实际奖励与完成状态以斗鱼返回结果为准。

### 一键签到会动我的关注列表吗

部分签到任务会临时关注并浏览指定的活动直播间。程序会在签到结束后尝试恢复原来的关注状态与观看历史；静默模式只跳过活动弹幕任务，仍可能执行这些步骤。

还原动作有失败的可能（网络中断等），此时执行结果里会明确报出"关注状态还原失败"或 "观看历史恢复失败"，你可以手动清理。介意这个行为请不要使用一键签到。

### 静默签到为什么没有完成活动弹幕任务

1.4.0 的斗鱼签到默认开启「静默模式」，会跳过尚未完成的活动弹幕任务，其他签到步骤照常执行。需要执行活动弹幕任务时，请先关闭静默模式，再开始签到；执行期间不能切换模式。

静默模式仍可能执行其他任务中的临时关注或道具消耗，请确认面板与回执中的范围和结果。签到、续牌与批量弹幕任务仍属于账号自动化操作，风险说明见[免责声明](../DISCLAIMER.md#三关于账号功能的重要风险提示)。

### 虎牙粉丝牌怎么打卡

从「工具 → 粉丝牌总览」或粉丝牌成长详情主动点击打卡。当天已经完成、状态未知或试用粉丝牌不能重复提交，完成状态以虎牙返回结果为准。

### 登录状态老是掉

平台凭据都有有效期。斗鱼登录过期时程序会自动尝试恢复，在「账号与认证」或「设置 → 账号与桌面」中也可以手动刷新登录状态。如果频繁掉登录，可能是账号在别处登录导致的。

## 斗鱼鱼吧

### 鱼吧在哪，随看和展开阅读有什么区别

从「控制台 → 工具 → 斗鱼鱼吧」打开，可选择正在看的斗鱼房间，或输入房间号、鱼吧 ID 与地址。随看适合边看边读，展开阅读提供更宽的正文与完整侧栏；切换时保留正在阅读的内容。

### 我关注的、收藏、赞过和排行榜在哪

随看中的常用导航提供已加入鱼吧、我关注的和热门推荐；排行榜、收藏与赞过在更多菜单中。展开阅读的侧栏显示全部入口。

热门推荐与排行榜可匿名浏览，排行榜采用平台近 7 天热度口径；个人内容需要登录斗鱼账号。帖子的收藏按钮用于主动收藏或取消。

### 鱼吧为什么不能发帖、上传图片或加入鱼吧

发帖与互动需要登录，并满足平台的成员或等级要求。当前支持纯文字动态、评论、回复、点赞、表态与收藏，尚未接入图片上传、完整图文编辑或加入／退出鱼吧；需要时请到平台官方页面操作。

写入请求超时后，先刷新确认是否已经成功，再决定是否重试，避免重复发布。

## 监控与导演模式

### 监控列表什么时候会通知

开播和下播都会通知，两个开关在设置里独立控制，可以只留开播。点击开播通知会直接把该房间加为播放窗口，点下播通知只是把程序窗口调到前台。

托盘菜单里能看到监控列表当前有几个在播。

### 导演模式是做什么的

它盯着各个房间的热度变化，谁在快速上涨就给谁加高亮边框，帮你在多个窗口里第一时间注意到哪边有事发生。

参与评分的指标有弹幕速率、贵宾数、热度、礼物，权重可以自己配，也能整体关掉。轮播和没开播的房间不参与判定 —— 那种情况下的弹幕和贵宾只说明有人在等，跟内容精彩程度无关。

## 像素补给站

### 课程能继续上次的讲解吗

课程默认继续未完成的讲解，暂停或切换课程后可续学；「从头讲解」用于重新练习。已经获得的任务奖励不会因复习重复发放。

补给站的金币、经验和成就记录在本机，与平台粉丝牌的亲密度或账号等级不同。迁移整个数据目录与导出布局、设置的范围见[安装说明](install.md#数据目录里有什么)。

## 布局与设置

### 有没有一键排列

有。星幕会自动编排，也可在构图工作台先预览再应用；自由和平铺布局提供均分网格、主副右栏和主副下栏。画中画需要重叠窗口，只在自由布局提供。选择后先查看预览，确认应用，再按需要手动微调。

### 星幕、自由和平铺布局有什么区别

星幕自动编排多路画面，可选择一个或多个重点，并让其他画面围绕重点排列；支持拖拽交换、固定格位、构图预览和按住 `Z` 临时巡看。自由布局下窗口可以任意摆放、重叠，像在 OBS 里摆场景；平铺布局下窗格铺满舞台、互不重叠，靠分隔线调整比例，还能切分、交换窗格。

在标题栏直接选择，或按 `Alt+T` 按星幕、自由、平铺循环切换。首次使用默认星幕；已有布局和存档继续恢复原来的模式，快捷键见 [README](../README.md#快捷键)。

### 星幕怎么放大一路、固定位置或交换画面

点击画面侧边的重点按钮加入或取消重点，`Shift` 点击只聚焦这一路；舞台方向键选窗，`Enter` 切换重点，`Shift+Enter` 仅聚焦当前画面，`Esc` 返回总览。聚焦只调整画面，不改变声音。

右键选择「固定格位」后，可用顶部或边缘手柄移动容器、四角手柄改大小；双击角部手柄贴合源画幅。拖动画面到另一画面交换内容，固定格位的容器保持在原处。按住 `Z` 临时放大，滚轮巡看，期间按住 `A` 可临时独听，松开恢复。

### 画中画布局和系统画中画有什么区别

画中画布局把多个窗口重叠摆在 LiveDeck 舞台中，只在自由布局提供。系统原生画中画把单路视频放到应用外的系统窗口，不会带出 LiveDeck 的字幕覆盖层或画面增强。

### 操作错了能撤销吗

能。布局操作（拖动、缩放、关窗、排列等）都可以用 `Ctrl+Z` 撤销、`Ctrl+Y` 重做，右键菜单底部也有撤销与重做。

### 布局会自动保存吗

会。当前布局实时保存，关掉程序再打开还是原样。

也可以在布局管理里把当前布局命名保存成一套，之后随时切回来，还能导出成文件备份。

### 窗口拖不动

大概是被锁定了。右键窗口在菜单里解锁；或者选中窗口后，在控制台的选区入口打开窗口操作菜单解锁。

另外，星幕下拖动画面用于交换位置，固定格位请用手柄调整；平铺下调整大小请拖窗格之间的分隔线。想任意摆放时在标题栏选择「自由」模式。

### 怎么精确对齐窗口

自由布局下拖动时靠近屏幕边缘或别的窗口会自动吸附，同时显示对齐辅助线。想放在吸附点之外的位置，按住 `Alt` 再拖就能临时关掉吸附。

### 设置能备份吗

设置面板里可以导出成文件，也可以导入恢复。恢复默认值只影响设置，不动当前布局、已保存的布局和开播监控列表。

### OLED 防烧屏怎么开启，能完全防止烧屏吗

在「设置 → 外观与舞台 → 观看舒适度」开启 OLED 防烧屏，默认关闭。开启后会轻微移动显示位置，闲置时逐渐调暗，并减弱视频中长时间不变的亮区；进行操作后会恢复相应亮度。

它只能减轻固定画面的持续显示负担，不能保证避免烧屏，也不能代替显示器自身的保护措施。原生画中画不受保护。视频分析在本机进行，不保存或上传画面。

### 全屏后怎么退出或打开控制台

按 `Esc` 或 `F11` 退出全屏；有浮层时 `Esc` 会先关闭浮层，星幕临时查看时先结束查看。移动鼠标也会显示顶部的「退出全屏」按钮。鼠标移到右上角唤出控制台入口，再点击展开；也可按反引号／波浪键直接开合。1.4.0 起不再从屏幕底边唤出控制台。

## 更新与公告

### 怎么检查更新

程序会自动检查，有新版本时在设置面板里提示。也可以在「设置 → 关于与更新 → 更新与公告」里手动点「检查更新」，标题栏公告入口可查看未读内容。

检查会获取公开的版本清单、说明和公告，不会附带观看记录。自动检查可以关闭，网络与缓存问题见下一项。

### 检查更新失败

大陆网络访问 GitHub 不稳定，程序会依次尝试多个加速地址，全都失败时会显示上次成功检查的结果。可以稍后再试，或直接访问 [Releases 页面](https://github.com/0xyk3r/livedeck-release/releases/latest) 手动看。

不想让程序发这类请求的话，可以在设置里关闭自动检查更新。

### 程序会自动下载安装更新吗

不会自动下载安装。检测到新版本后，你可以在应用内主动下载，程序会在落盘后校验 SHA256，但不会自动运行或安装；也可以在系统浏览器中打开下载页，自己选择下载地址。

### 更新会丢配置吗

按原位置升级会继续使用原数据目录。先从托盘退出程序，再覆盖安装或替换便携版 exe；便携版要保留同级的 `LiveDeckData`。更换版本类型或移动到其他目录，不会自动搬迁配置。

建议更新前顺手导出一次布局和设置。

## 其他

### 日志在哪

- 安装版：`%AppData%\LiveDeck\logs\`
- 便携版：exe 同级的 `LiveDeckData\logs\`

按日期分文件，命名如 `livedeck-2026-08-29.log`。

在文件资源管理器地址栏里粘 `%AppData%\LiveDeck\logs` 回车可以直接打开。

提 Issue 时附上出问题当天的日志会快很多。日志里不含账号密码，但可能包含房间号和昵称，介意的话可以先看一遍再贴。

### 关闭窗口后程序还在后台

默认行为是最小化到系统托盘，托盘图标右键可以退出。想改成点关闭就直接退出，在设置里改「关闭按钮行为」。

### 有 macOS / Linux 版吗

暂时没有。

### 怎么反馈问题

到 [Issues](https://github.com/0xyk3r/livedeck-release/issues) 提。麻烦附上版本号、复现步骤，以及相关日志。
