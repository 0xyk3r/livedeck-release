# 常见问题

## 播放相关

### 支持哪些平台

斗鱼、虎牙、哔哩哔哩（1.2.0 起）。三个平台的直播间可以混排在同一个布局里；录像与视频方面支持斗鱼录像、虎牙录像和 B 站视频（含分 P），1.3.0 起还可浏览 B 站主播已公开的直播回放目录。

回看弹幕补全、PK 比分条、鱼吧、一键签到与一键续牌目前只有斗鱼有。

### 房间号在哪看

各平台网页版地址里的那串数字，比如斗鱼 `douyu.com/9999`、虎牙 `huya.com/11342412`、B 站 `live.bilibili.com/21452505`。也可以不找房间号，直接把整条链接粘进去；B 站还支持 BV / AV 号和 App 分享文本。

斗鱼靓号也能直接用。程序内部会自动识别靓号与真实房间号指向的是同一个房间，不会重复开窗。

### 一直显示加载中 / 反复重试

依次排查：

1. 主播是否真的在播 —— 未开播时取不到流
2. 浏览器里能否正常打开这个房间 —— 不能的话是网络或平台问题，与本程序无关
3. 换个房间试试 —— 只有个别房间不行，可能是该房间用了特殊的流格式
4. 手动降低清晰度 —— 高码率流在带宽不足时会一直缓冲

程序对取流失败是无限重试的（退避上限 5 秒），所以"一直在重试"通常意味着上游确实拿不到流，而不是程序卡住了。

### 画面卡顿、掉帧

同看多路高清直播对硬件要求不低。一个 1080p60 的流解码开销就不小，叠加多路再加上全屏弹幕的渲染，很容易吃满 GPU。

按效果排序的缓解手段：

1. 手动降低清晰度 —— 效果最明显
2. 减少同时播放的窗口数
3. 关闭弹幕
4. 关掉其他占用显卡的程序

### 某条线路一直卡

在窗口控制栏里换一条线路。平台会为同一个房间下发多条 CDN 线路，各条的负载和到你这里的路由质量不一样，换一条往往就好了。清晰度也可以一起降一档试试。

### 声音和画面不同步

先试试重载那个窗口。

如果是主播开多人连麦时出现的，通常在连麦结束后自行恢复 —— 这类失步源于主播端在加人或切场景时重建了音频编码器。程序已针对这种情况做了时钟重锚处理，若仍然发生，欢迎提 Issue 并注明房间号与当时的场景。

「时间微调」会一起移动画面与声音，用于调整不同直播之间的先后，不能单独修复同一路直播里的音画失步。

### 多个比赛视角不同步，怎么对齐

打开直播窗口控制栏的计时器按钮；窗口较窄时，从「更多控制 → 时间微调」进入。可以手动增加 0–30 秒附加延迟，按 0.1、0.5 或 1 秒微调；0 表示不添加额外延迟，不代表平台直播本身没有延迟。

也可以选择另一路直播作为参照，用「共同声音」采集约 24 秒的两路音轨并寻找时差，或用「画面时钟」同时截图，手动填写同一个游戏时钟的读数。查看建议后点击「应用对齐」才会调整播放；画面和声音一起移动，弹幕仍然实时显示。

声音比对适合两路包含相同比赛或游戏声音的情况，识别范围为前后各 12 秒。解说盖住游戏声、音轨不同、重复音乐或时差过大时可能无法匹配，可改用画面时钟或手动微调。画面时钟需要自己读数，不会自动识别截图中的文字。分析在本机进行，不使用麦克风，也不上传声音或截图。

### 有的房间没声音

检查四处：窗口自己的音量、全局音量、是否开了全局静音（底部控制台的音量按钮）、以及是否有别的房间处于 SOLO 状态 —— SOLO 会把其余房间全部静音。Windows 音量合成器里也可能单独把程序静音了。

### 怎么只听一个房间的声音

在窗口控制栏点 SOLO，其余房间会全部静音。再点一次退出。控制台上会显示当前 SOLO 的是哪个房间，点那里也能退出。

### 回放怎么用

支持回放的直播间开窗后，控制栏会出现进度条，可以拖动。不支持回放的房间不显示进度条。

### 怎么查 B 站主播的直播录像

打开「发现 → B 站 → 录像」，输入直播房间号、主播空间链接或该主播的视频链接；也可直接选择正在看的 B 站主播。找到回放后，可以选择分 P 并加入布局观看。

这里只展示主播已公开发布的直播回放，不是所有主播都会提供，也不代表完整的直播历史。暂时无法读取时可稍后刷新；「暂无公开回放」不代表该主播从未开播。

### 斗鱼公会目录去哪了

提供公会数据的第三方服务已停运，1.3.0 移除了公会目录和名册补录。仍可通过分类、搜索、关注查找房间；团播或赛事活动可以在「发现 → 斗鱼 → 直播 → 团播活动」中查找。团播活动并非完整的公会名册，也不保证收录所有活动。

## 弹幕相关

### 弹幕不显示

1. 底部控制台的「全局弹幕」开关是否打开
2. 该窗口是否单独关闭了弹幕（控制栏上的按钮）
3. 过滤规则是否把弹幕全过滤掉了 —— 设置里检查关键词、昵称、UID、等级、长度这几项，注意昵称、UID、等级是按平台分别设置的
4. 冷门房间可能确实没人说话

### 关掉某个窗口的弹幕后，通知也没了？

不会。单窗口关闭弹幕只是停止在屏幕上显示，弹幕连接依然保持，所以进场提醒、礼物提醒、关注用户通知、房间榜单和弹幕速率统计都照常工作。

### 发不出弹幕

需要先登录对应平台的账号。另外平台本身对发言有限制：等级要求、发言间隔、房间禁言、账号被禁言等，这些限制程序无法绕过。

### 彩色弹幕选项是灰的

彩色弹幕需要对应的账号权限（等级或贵族等），权限由平台判定。程序只显示你当前在该房间实际可用的颜色。

### 怎么找到自己刚发的弹幕

登录对应平台后，自己的弹幕会显示专属标记与下划线。识别依据是当前登录账号，昵称相同的其他用户不会被标成自己。

### 神秘人的消息卡能看到真实昵称吗

不能。斗鱼神秘人弹幕有独立样式，但消息卡仍显示平台提供的匿名身份。

## 账号相关

### 登录安全吗

登录在各平台自己的官方登录页面中完成，账号密码不经过本程序的任何代码。登录后的凭据只存在你本机的数据目录里，不上传任何服务器。

但**本机的凭据安全取决于你本机的安全状况**。便携版的 `LiveDeckData` 目录里包含登录状态，不要上传网盘或分享给他人。公用电脑上用完请退出登录。

### 用第三方工具登录、发弹幕会不会封号

**有风险，请自行判断。** 在平台看来，通过本程序发弹幕、关注、切换粉丝牌等操作来自非官方客户端，可能违反平台用户协议，也可能被风控识别。三个平台都一样。

### 一键签到 / 一键续牌 / 批量弹幕任务会不会封号

**风险更高，请自行判断。** 这些功能只面向斗鱼账号，由程序批量执行原本需要手动操作的任务，可能违反斗鱼用户协议，也可能被风控识别为异常。开发者无法预知平台的判定标准，不对账号处罚承担责任。

不用这些功能不影响看直播，观看和显示弹幕不需要登录。详见 [免责声明](../DISCLAIMER.md#三关于账号功能的重要风险提示)。

### 粉丝牌总览在哪，能做什么

从「工具 → 粉丝牌总览」进入，连接相应平台账号后，就能集中查找斗鱼、虎牙与 B 站的粉丝牌，按平台、主播、等级或点亮状态筛选，查看成长并进入直播间。斗鱼、虎牙可展示平台提供的任务状态，B 站主要展示成长数值与点亮状态。

斗鱼还可查看生效的主播双倍卡与可读取的综合倍率；综合倍率无法读取时会注明卡片倍率。在粉丝牌详情可主动向对应房间赠送背包荧光棒，赠送会消耗所选数量的道具。仅查看总览不会自动发弹幕或赠礼。

### 批量弹幕任务会发到哪些房间

范围是总览已加载的全部斗鱼粉丝牌房间，不受当前平台筛选、搜索或分页影响。程序检查任务状态后，跳过已完成或没有对应任务的房间，向待完成的房间逐个发送你填写的弹幕；状态不明时不发送，发送失败时停止。

开始前可以修改内容，过程中可以停止后续发送；已经提交的请求仍可能完成。默认文案中的「+10 亲密度」不是奖励承诺，实际奖励与完成状态以斗鱼返回结果为准。

### 一键签到会动我的关注列表吗

会，但会还原。部分签到任务（例如星推关注任务）要求关注并浏览指定的活动直播间才能完成，程序会在签到结束后自动取消这些关注、并从观看历史里移除对应记录。

还原动作有失败的可能（网络中断等），此时执行结果里会明确报出"关注状态还原失败"或 "观看历史恢复失败"，你可以手动清理。介意这个行为请不要使用一键签到。

### 登录状态老是掉

平台凭据都有有效期。斗鱼登录过期时程序会自动尝试恢复，在「账号与认证」或「设置 → 账号与桌面」中也可以手动刷新登录状态。如果频繁掉登录，可能是账号在别处登录导致的。

## 监控与导演模式

### 监控列表什么时候会通知

开播和下播都会通知，两个开关在设置里独立控制，可以只留开播。点击开播通知会直接把该房间加为播放窗口，点下播通知只是把程序窗口调到前台。

托盘菜单里能看到监控列表当前有几个在播。

### 导演模式是做什么的

它盯着各个房间的热度变化，谁在快速上涨就给谁加高亮边框，帮你在多个窗口里第一时间注意到哪边有事发生。

参与评分的指标有弹幕速率、贵宾数、热度、礼物，权重可以自己配，也能整体关掉。轮播和没开播的房间不参与判定 —— 那种情况下的弹幕和贵宾只说明有人在等，跟内容精彩程度无关。

## 布局与设置

### 有没有一键排列

有。布局面板里提供均分网格、主副（右栏 / 下栏）、画中画几种快速版式。选择后先查看预览，点击「应用布局」才会改变当前窗口，之后仍可以手动微调。

### 自由布局和平铺布局有什么区别

自由布局下窗口可以任意摆放、重叠，像在 OBS 里摆场景；平铺布局下窗格铺满舞台、互不重叠，靠拖动窗格之间的分隔线调整比例，还能切分、交换窗格。按 `Alt+T` 切换，快捷键见 [README](../README.md#快捷键)。

### 操作错了能撤销吗

能。布局操作（拖动、缩放、关窗、排列等）都可以用 `Ctrl+Z` 撤销、`Ctrl+Y` 重做，右键菜单底部也有撤销与重做。

### 布局会自动保存吗

会。当前布局实时保存，关掉程序再打开还是原样。

也可以在布局管理里把当前布局命名保存成一套，之后随时切回来，还能导出成文件备份。

### 窗口拖不动

大概是被锁定了。右键窗口在菜单里解锁；或者选中窗口后，在底部控制台的选区入口打开窗口操作菜单解锁。

另外，平铺布局下窗口不能自由拖动，要调整大小请拖窗格之间的分隔线，想自由摆放请按 `Alt+T` 切回自由布局。

### 怎么精确对齐窗口

自由布局下拖动时靠近屏幕边缘或别的窗口会自动吸附，同时显示对齐辅助线。想放在吸附点之外的位置，按住 `Alt` 再拖就能临时关掉吸附。

### 设置能备份吗

设置面板里可以导出成文件，也可以导入恢复。恢复默认值只影响设置，不动当前布局、已保存的布局和开播监控列表。

### OLED 防烧屏怎么开启，能完全防止烧屏吗

在「设置 → 外观 → OLED 防烧屏」开启，默认关闭。开启后会轻微移动显示位置，闲置时逐渐调暗，并减弱视频中长时间不变的亮区；进行操作后会恢复相应亮度。

它只能减轻固定画面的持续显示负担，不能保证避免烧屏，也不能代替显示器自身的保护措施。原生画中画不受保护。视频分析在本机进行，不保存或上传画面。

### 全屏后怎么退出或打开控制台

按 `Esc` 或 `F11` 退出全屏；移动鼠标也会显示顶部的「退出全屏」按钮。鼠标移到屏幕底边可展开控制台。

## 更新与公告

### 怎么检查更新

程序会自动检查，有新版本时在设置面板里提示。也可以在「设置 → 关于 → 更新与公告」里手动点「检查更新」。

检查只请求一个很小的静态文件，不上传任何个人信息。

### 检查更新失败

大陆网络访问 GitHub 不稳定，程序会依次尝试多个加速地址，全都失败时会显示上次成功检查的结果。可以稍后再试，或直接访问 [Releases 页面](https://github.com/0xyk3r/livedeck-release/releases/latest) 手动看。

不想让程序发这类请求的话，可以在设置里关闭自动检查更新。

### 程序会自动下载安装更新吗

不会自动下载安装。检测到新版本后，你可以在应用内主动下载，程序会在落盘后校验 SHA256，但不会自动运行或安装；也可以在系统浏览器中打开下载页，自己选择下载地址。

### 更新会丢配置吗

不会。安装版覆盖安装保留全部数据。便携版用新 exe 替换旧的，保留同级的 `LiveDeckData` 目录即可。

建议更新前顺手导出一次布局和设置。

## 其他

### 日志在哪

- 安装版：`%AppData%\LiveDeck\logs\`
- 便携版：exe 同级的 `LiveDeckData\logs\`

按日期分文件，命名如 `livedeck-2026-08-29.log`。

在文件资源管理器地址栏里粘 `%AppData%\LiveDeck\logs` 回车可以直接打开。

提 Issue 时附上出问题当天的日志会快很多。日志里不含账号密码，但可能包含房间号和昵称，介意的话可以先看一遍再贴。

### 关闭窗口后程序还在后台

默认行为是最小化到系统托盘，托盘图标右键可以退出。想改成点关闭就直接退出，在设置里改「关闭按钮行为」。

### 有 macOS / Linux 版吗

暂时没有。

### 怎么反馈问题

到 [Issues](https://github.com/0xyk3r/livedeck-release/issues) 提。麻烦附上版本号、复现步骤，以及相关日志。
