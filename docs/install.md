# 安装说明

## 系统要求

- 64 位 Windows 10（1809 及以上）或 Windows 11
- 建议至少 8 GB 内存；多路高清播放、插帧、超分与本地字幕需要更多 CPU／GPU 资源
- 能访问所观看平台及其媒体服务器的网络环境

目前没有 32 位、ARM、macOS 或 Linux 安装包。

## 选安装版还是便携版

| | 安装版 `Setup.exe` | 便携版 `Portable.exe` |
| --- | --- | --- |
| 安装过程 | 可选安装位置 | 无，双击运行 |
| 开始菜单／桌面图标 | 有 | 无 |
| 数据位置 | `%AppData%\LiveDeck` | exe 同级的 `LiveDeckData` |
| 卸载方式 | Windows 已安装的应用 | 删除 exe；按需保留或删除数据目录 |
| 适合 | 常用电脑 | U 盘或需要独立存放配置的场景 |

两种版本功能相同，数据目录各自独立。从安装版改用便携版，或同时运行两种版本，不会自动共享布局、设置和登录状态。

便携版应放在可以写入数据的目录。迁移时把 exe 与 `LiveDeckData` 一起移动；只移动 exe，原配置不会自动出现在新位置。数据目录包含登录凭据，请勿上传网盘或分享给他人。

## 下载

官方发布页：[LiveDeck Releases](https://github.com/0xyk3r/livedeck-release/releases/latest)。选择需要的安装版或便携版。

大陆网络直连较慢时，可在原始下载地址前拼接代理前缀。以 1.4.0 安装版为例：

```text
# 原始地址
https://github.com/0xyk3r/livedeck-release/releases/download/v1.4.0/LiveDeck-1.4.0-x64-Setup.exe

# 加速地址
https://gh-proxy.com/https://github.com/0xyk3r/livedeck-release/releases/download/v1.4.0/LiveDeck-1.4.0-x64-Setup.exe
```

可用前缀：`https://gh-proxy.com/`、`https://v6.gh-proxy.org/`、`https://ghfast.top/`。这些是第三方公益服务，可能限流或失效；下载后建议核对发布页的 SHA256。

## 核对 SHA256

发布页为安装版与便携版分别列出 SHA256。在 PowerShell 中运行与所下载文件对应的命令：

```powershell
Get-FileHash .\LiveDeck-1.4.0-x64-Setup.exe -Algorithm SHA256
Get-FileHash .\LiveDeck-1.4.0-x64-Portable.exe -Algorithm SHA256
```

将 `Hash` 与官方下载页对应文件的值比较，大小写不影响。摘要相同说明文件与发布产物一致；不一致时不要运行，换个来源重新下载。请从官方发布页取得校验值。

## Windows 提示「Windows 已保护你的电脑」

本程序未使用代码签名证书，Windows SmartScreen 可能提示「未知发布者」。先确认来源并核对 SHA256，再选择「更多信息 → 仍要运行」。浏览器若在下载阶段拦截，可在下载列表检查来源后选择保留。

新版本文件发生变化，可能再次出现提示。文件摘要用于检查完整性，不代表操作系统已验证发布者身份。

## 杀毒软件报毒

安全软件可能对未签名应用报「可疑行为」，仅凭提示不能判断是否误报。先核对来源与 SHA256，并查看安全软件给出的具体名称和行为；可以使用多引擎扫描辅助排查。

如果摘要不一致或来源不明，不要放行。仍有疑问时，请附告警名称、版本和下载来源向 [Issues](https://github.com/0xyk3r/livedeck-release/issues) 反馈。

## 安装与升级

安装版双击安装程序，按向导选择位置。更新时先退出 LiveDeck；若程序收在托盘中，请从托盘菜单退出，再用新安装包覆盖安装。

便携版更新时先退出旧程序，再在原目录用新 exe 替换旧 exe，保留同级 `LiveDeckData`。文件名中的版本号可以变化，数据目录位置要保持一致。

升级前建议导出布局与设置。1.4.0 的主要操作调整是控制台移到标题栏，以及斗鱼签到默认静默；详见[更新说明](../CHANGELOG.md#140--2026-11-18)。

## 可选功能需要下载什么

| 功能 | 额外资源与条件 |
| --- | --- |
| 基础直播、录像与视频 | 无需额外模型或组件 |
| 本地语音字幕 | 在「设置 → 实时字幕」下载 Windows CPU 引擎与语音模型；翻译需要访问字幕服务 |
| Echo 在线字幕 | 无需本地语音模型，使用时发送播放器音频至在线服务 |
| NVIDIA 插帧／超分 | 在「设置 → 画面增强」安装可选 VFX 组件，阅读许可并检查所选模型兼容性 |
| AMD 插帧／超分 | 依赖显卡驱动提供的能力，以应用兼容性检查为准 |
| 通用 GPU 插帧／超分 | 无需原生组件，需要硬件加速与 WebGL 2 |
| 音频增强与响度平衡 | 随应用提供，无需额外下载模型 |

组件可安装与功能可运行是不同条件，HDR、高目标帧率和高分辨率还受来源、账号、显示输出、显卡与负载影响。完整说明见[常见问题](faq.md)。

## 卸载

安装版：在 Windows「设置 → 应用 → 已安装的应用」中卸载。配置保留在 `%AppData%\LiveDeck`；确认不再需要后可手动删除。

便携版：删除 exe 即可移除程序；删除 `LiveDeckData` 会同时删除布局、设置、登录状态及已下载的本地资源，操作前请按需备份。

## 数据目录里有什么

| 项目 | 内容 |
| --- | --- |
| `window-state.json` | 窗口大小、位置和显示状态 |
| `app-prefs.json` | 关闭按钮行为等应用偏好 |
| `update-state.json` | 更新检查结果与公告已读状态 |
| `logs/` | 运行日志 |
| `speech-subtitles/` | 已下载的字幕模型与引擎 |
| Chromium Profile 与本地存储 | 登录状态、布局、设置、监控和本地成长等数据 |

配置与本地资源都位于对应的数据目录中。导出布局与设置可用于恢复这两类数据，不等于备份整个数据目录。
